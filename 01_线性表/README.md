# 第一章 线性表

## 概念定义

**线性表**是具有相同数据类型的 n（n≥0）个数据元素的有限序列。  
线性表是最基本、最简单、也是最常用的一种数据结构。

### 线性表的特点
- 存在唯一的第一个元素（表头）
- 存在唯一的最后一个元素（表尾）
- 除表头外，每个元素都有且仅有一个直接前驱
- 除表尾外，每个元素都有且仅有一个直接后继

---

## 核心特性对比

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| 存储方式 | 连续内存 | 离散内存 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1)（已知位置） |
| 空间利用率 | 高（无额外指针） | 低（需额外指针域） |
| 扩容 | 困难（需重新分配） | 容易 |

---

## 时间复杂度分析

### 顺序表
- 按位查找：**O(1)**
- 按值查找：**O(n)**
- 插入：**O(n)**（平均移动 n/2 个元素）
- 删除：**O(n)**（平均移动 (n-1)/2 个元素）

### 链表
- 按位查找：**O(n)**
- 按值查找：**O(n)**
- 插入（已知前驱）：**O(1)**
- 删除（已知前驱）：**O(1)**

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **顺序表** 插入第 i 个位置需移动 **n-i+1** 个元素，删除第 i 个位置需移动 **n-i** 个元素
2. ⭐⭐⭐ **带头结点链表** 与不带头结点链表的区别——带头结点操作更统一
3. ⭐⭐⭐ **循环队列** 判满：`(rear+1)%MaxSize == front`，判空：`rear == front`
4. ⭐⭐ **栈** 的应用：括号匹配、表达式求值、递归模拟
5. ⭐⭐ **链表逆置** 是高频考题
6. ⭐ 双链表插入删除需修改前后两个方向的指针

---

## 历年真题关注点

- 链表的逆置、合并有序链表
- 循环队列的判满判空条件
- 栈的出栈序列合法性判断（Catalan数）
- 用两个栈模拟队列，用两个队列模拟栈
