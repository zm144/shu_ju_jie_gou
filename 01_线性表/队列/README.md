# 队列（Queue）

## 概念定义

**队列**是只允许在一端进行插入（**队尾 rear**），另一端进行删除（**队头 front**）的线性表。
- 特点：**先进先出（FIFO, First In First Out）**

---

## 循环队列

为解决"假溢出"问题，将顺序队列设计为循环结构：
- 队空条件：`front == rear`
- 队满条件：`(rear + 1) % MaxSize == front`（牺牲一个存储单元）
- 队列长度：`(rear - front + MaxSize) % MaxSize`

---

## 时间/空间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| EnQueue | O(1) |
| DeQueue | O(1) |
| GetHead | O(1) |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 循环队列**判满**：`(rear+1)%MaxSize == front`（注意与判空区分）
2. ⭐⭐⭐ 循环队列**判空**：`rear == front`
3. ⭐⭐ 队列典型应用：**BFS广度优先搜索**、**操作系统进程调度**、**打印队列**
4. ⭐⭐ 双端队列（deque）：两端都可入队出队
5. ⭐ 用两个队列模拟栈的思路
