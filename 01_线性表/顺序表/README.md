# 顺序表（Sequential List）

## 概念定义

顺序表是用一组**地址连续**的存储单元依次存储线性表的数据元素，使得逻辑上相邻的两个元素在物理位置上也相邻。

### 存储结构
```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];  // 顺序表元素
    int length;         // 顺序表当前长度
} SeqList;
```

---

## 核心特性

- **随机存取**：可以在 O(1) 时间内访问任意元素
- **存储密度高**：每个节点只存储数据元素本身
- **插入删除效率低**：需要移动大量元素

---

## 时间复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按位查找 GetElem(i) | O(1) | 直接通过下标访问 |
| 按值查找 LocateElem(e) | O(n) | 需要遍历比较 |
| 插入 ListInsert(i, e) | O(n) | 平均移动 n/2 个元素 |
| 删除 ListDelete(i) | O(n) | 平均移动 (n-1)/2 个元素 |
| 求表长 Length() | O(1) | 直接返回 length |

## 空间复杂度

- **O(n)** — 需要连续存储 n 个元素

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 插入位置 i（1-based）时，需将 **第 i 个到第 n 个**元素后移（共移动 n-i+1 个），平均移动次数 = n/2
2. ⭐⭐⭐ 删除位置 i 时，需将 **第 i+1 个到第 n 个**元素前移（共移动 n-i 个），平均移动次数 = (n-1)/2
3. ⭐⭐ 顺序表可用**动态分配**（malloc/realloc）实现扩容
4. ⭐ 注意下标从 0 开始还是从 1 开始的区别（考研通常用 1-based）
