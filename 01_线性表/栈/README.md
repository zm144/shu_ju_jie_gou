# 栈（Stack）

## 概念定义

**栈**是只允许在一端进行插入或删除操作的线性表。允许操作的一端称为**栈顶（top）**，另一端称为**栈底（bottom）**。
- 特点：**后进先出（LIFO, Last In First Out）**

---

## 核心操作

| 操作 | 说明 |
|------|------|
| InitStack(S) | 初始化栈 |
| Push(S, x) | 入栈（压栈） |
| Pop(S, &x) | 出栈（弹栈） |
| GetTop(S, &x) | 读栈顶元素（不删除） |
| StackEmpty(S) | 判断栈空 |

---

## 时间/空间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| Push | O(1) |
| Pop | O(1) |
| GetTop | O(1) |

- 顺序栈空间复杂度：**O(n)**（预分配）
- 链栈空间复杂度：**O(n)**（动态分配）

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 栈的典型应用：**括号匹配**、**表达式转换**（中缀→后缀）、**函数调用栈**
2. ⭐⭐⭐ n 个元素入栈的合法出栈序列数 = **Catalan数** = C(2n,n)/(n+1)
3. ⭐⭐ 顺序栈判空：`top == -1`，判满：`top == MaxSize-1`
4. ⭐⭐ 共享栈：两个栈共享一段连续空间，从两端向中间增长
5. ⭐ 递归可以用栈来消除（迭代替代递归）

---

## 历年真题关注点

- 给定入栈序列，判断某出栈序列是否合法
- 括号匹配算法实现
- 利用栈实现中缀表达式转后缀表达式
- 用两个栈模拟队列
