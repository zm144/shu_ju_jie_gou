# 链表（Linked List）

## 概念定义

**链表**是通过一组任意的存储单元来存储线性表的数据元素（存储单元可以是不连续的）。每个结点除存储数据元素外，还需存储一个指向其后继的指针。

### 单链表结构
```c
typedef struct LNode {
    int data;           // 数据域
    struct LNode *next; // 指针域
} LNode, *LinkList;
```

---

## 核心特性

- **动态存储**：不需要预先分配固定大小内存
- **插删高效**：已知位置时 O(1)
- **不支持随机访问**：按位查找需 O(n)
- **带头结点**：可统一空表和非空表的操作

---

## 时间复杂度分析

| 操作 | 单链表 | 双链表 |
|------|--------|--------|
| 查找第 i 个元素 | O(n) | O(n) |
| 在已知结点后插入 | O(1) | O(1) |
| 删除已知结点后继 | O(1) | O(1) |
| 删除已知结点本身 | O(n)（单）| O(1)（双）|
| 尾部插入 | O(n) | O(1)（有尾指针）|

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **带头结点**的链表中，头指针始终指向头结点，头结点的 next 指向第一个数据结点
2. ⭐⭐⭐ **链表逆置**是高频考题，需掌握头插法逆置
3. ⭐⭐⭐ **合并两个有序链表**，时间复杂度 O(m+n)
4. ⭐⭐ 判断链表是否有环：快慢指针法（Floyd判圈）
5. ⭐⭐ 找链表倒数第 k 个结点：双指针法
6. ⭐ 双链表删除结点 p：`p->prior->next = p->next; p->next->prior = p->prior;`

---

## 历年真题关注点

- 链表逆置（头插法）
- 合并两个有序链表为有序链表
- 删除值为 x 的所有结点
- 判断链表是否有环及找环入口
- 找链表的中间结点
