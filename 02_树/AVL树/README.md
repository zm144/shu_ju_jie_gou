# AVL树（平衡二叉搜索树）

## 概念定义

**AVL树**是带自平衡机制的二叉搜索树，满足：
- 任意结点的**平衡因子 BF = 左子树高度 - 右子树高度，|BF| ≤ 1**
- 任意子树也满足AVL树性质

### 平衡因子（Balance Factor）
- BF = 左子树高度 - 右子树高度
- AVL树中，BF ∈ {-1, 0, 1}

---

## 四种旋转

| 失衡类型 | 插入位置 | 旋转方式 |
|---------|---------|---------|
| LL型 | 左孩子的左子树 | 右旋（单旋） |
| RR型 | 右孩子的右子树 | 左旋（单旋） |
| LR型 | 左孩子的右子树 | 先左旋后右旋（双旋） |
| RL型 | 右孩子的左子树 | 先右旋后左旋（双旋） |

---

## 时间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 查找 | O(log n) |
| 插入 | O(log n) |
| 删除 | O(log n) |

高度 h = O(log n)，保证了最坏情况下的高效查找

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **四种旋转类型的判断和操作**（LL/RR/LR/RL）
2. ⭐⭐⭐ LL旋转（右旋）：将失衡结点的**左孩子**提升为新根
3. ⭐⭐⭐ RR旋转（左旋）：将失衡结点的**右孩子**提升为新根
4. ⭐⭐ LR旋转 = 先对左孩子做RR旋转，再对自身做LL旋转
5. ⭐⭐ RL旋转 = 先对右孩子做LL旋转，再对自身做RR旋转
6. ⭐ 含n个结点的AVL树高度 h = O(log n)
