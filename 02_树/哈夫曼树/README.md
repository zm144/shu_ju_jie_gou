# 哈夫曼树（Huffman Tree）

## 概念定义

**哈夫曼树**（最优二叉树）：给定 n 个权值作为 n 个叶结点，构造一棵二叉树，使得该树的**带权路径长度（WPL）最小**。

### 相关概念
- **路径长度**：从根到某结点的路径上边的数量
- **带权路径长度（WPL）**：WPL = Σ(wᵢ × lᵢ)，wᵢ 为叶结点权值，lᵢ 为路径长度
- **哈夫曼编码**：利用哈夫曼树，对频率高的字符用短编码，频率低的用长编码（前缀码）

---

## 构造算法

1. 将 n 个权值作为 n 棵只有根结点的树
2. 每次从森林中选取**权值最小的两棵树**合并，新树根的权值 = 两子树根权值之和
3. 重复步骤2，直到只剩一棵树

**结果**：n 个叶结点的哈夫曼树共有 **2n-1** 个结点（无度为1的结点）

---

## 时间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 构建哈夫曼树（朴素） | O(n²) |
| 构建哈夫曼树（优先队列）| O(n log n) |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ WPL计算（需手动演算）
2. ⭐⭐⭐ 哈夫曼树中**无度为1的结点**
3. ⭐⭐⭐ 哈夫曼编码是**前缀码**（任何编码不是另一编码的前缀）
4. ⭐⭐ n个叶结点构成的哈夫曼树有 **2n-1** 个结点
5. ⭐⭐ 哈夫曼编码的**解码过程**（从根遍历树）
6. ⭐ 哈夫曼树不唯一（权值相同时选择不同），但WPL唯一
