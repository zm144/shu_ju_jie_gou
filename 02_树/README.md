# 第二章 树

## 概念定义

**树**是 n（n≥0）个结点的有限集合，当 n=0 时称为**空树**。
树的特点：
- 有且仅有一个特定的称为**根（Root）**的结点
- 当 n>1 时，其余结点可分为 m（m>0）个互不相交的子树

**二叉树**是每个结点最多有两棵子树的树，分为左子树和右子树，次序不能互换。

---

## 重要性质

### 二叉树性质
1. 第 i 层最多有 **2^(i-1)** 个结点（i≥1）
2. 深度为 h 的二叉树最多有 **2^h - 1** 个结点
3. **n₀ = n₂ + 1**（叶结点数 = 度为2的结点数 + 1）⭐⭐⭐
4. 完全二叉树中，若 n 为偶数，则有一个度为1的结点；若 n 为奇数，则度为1的结点为0个

### 完全二叉树性质（顺序存储下标关系）
- 父结点：`⌊i/2⌋`
- 左孩子：`2i`
- 右孩子：`2i+1`

---

## 各类树对比

| 类型 | 特点 | 主要应用 |
|------|------|---------|
| 二叉搜索树(BST) | 左<根<右 | 动态查找 |
| AVL树 | 平衡因子|≤1 | 高效查找 |
| 哈夫曼树 | 带权路径长度最小 | 数据压缩 |
| B树(m阶) | 每结点m/2到m个孩子 | 磁盘索引 |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **n₀ = n₂ + 1** 必背（叶结点与度2结点关系）
2. ⭐⭐⭐ 二叉树**四种遍历**（前、中、后、层序）及其迭代实现
3. ⭐⭐⭐ 由**中序+前序**或**中序+后序**唯一确定二叉树
4. ⭐⭐⭐ AVL树四种旋转：LL、RR、LR、RL
5. ⭐⭐ 哈夫曼树的构造（每次选最小两个合并）
6. ⭐⭐ B树的阶数、关键字个数范围
7. ⭐ 线索二叉树的概念（将空指针利用起来存储前驱/后继）
