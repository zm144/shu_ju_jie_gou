# 二叉树（Binary Tree）

## 概念定义

**二叉树**是每个结点最多有两棵子树的树形结构，子树分为**左子树**和**右子树**，次序不可互换。

### 特殊二叉树
- **满二叉树**：每层结点数达到最大值（深度为h有 2^h-1 个结点）
- **完全二叉树**：只有最后一层不满，且结点从左往右紧密排列
- **二叉搜索树（BST）**：左子树所有键值 < 根 < 右子树所有键值
- **平衡二叉树（AVL）**：任意结点左右子树高度差 ≤ 1

---

## 遍历方式

| 遍历 | 访问顺序 | 特点 |
|------|---------|------|
| 前序（NLR） | 根→左→右 | 第一个访问根 |
| 中序（LNR） | 左→根→右 | BST中序结果有序 |
| 后序（LRN） | 左→右→根 | 最后访问根 |
| 层序 | 按层从左到右 | 使用队列 |

---

## 时间/空间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 遍历（任意方式） | O(n) |
| 求高度 | O(n) |
| 统计结点数 | O(n) |

## ⭐ 考研重点提示

1. ⭐⭐⭐ **n₀ = n₂ + 1**（叶结点数 = 度2结点数+1），推导：总边数 n-1 = n₁+2n₂，n=n₀+n₁+n₂
2. ⭐⭐⭐ 中序遍历+前序/后序可唯一确定二叉树（但前序+后序不能）
3. ⭐⭐⭐ 迭代中序遍历（用栈模拟）是常考题
4. ⭐⭐ 完全二叉树顺序存储时，父子结点下标关系：父=⌊i/2⌋，左孩子=2i，右孩子=2i+1
5. ⭐ 线索化：将空指针改为指向前驱/后继
