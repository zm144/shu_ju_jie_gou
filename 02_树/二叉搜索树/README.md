# 二叉搜索树（Binary Search Tree，BST）

## 概念定义

**二叉搜索树**（又称二叉排序树、二叉查找树）满足：
- 左子树所有结点的值 < 根结点的值
- 右子树所有结点的值 > 根结点的值
- 左右子树也各自是二叉搜索树

**中序遍历BST得到的序列是有序递增序列** ⭐

---

## 时间复杂度

| 操作 | 平均 | 最坏（退化为链表） |
|------|------|-----------------|
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

最坏情况：输入数据有序，BST退化为单链表（高度=n）

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ BST**删除**操作分三种情况（无孩子/一个孩子/两个孩子）
2. ⭐⭐⭐ 删除有两个孩子的结点：用**中序后继**（右子树最小值）或**中序前驱**（左子树最大值）替换
3. ⭐⭐ BST中序遍历 = 有序序列
4. ⭐⭐ n个不同关键字可构成的BST数量 = Catalan数 = C(2n,n)/(n+1)
5. ⭐ BST的平均查找长度 ASL ≈ log₂(n+1) - 1（平衡时）

- BST删除结点的三种情况
