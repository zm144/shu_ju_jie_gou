# B树（B-Tree）

## 概念定义

**m阶B树**是满足以下条件的多路平衡查找树：
1. 每个结点最多有 **m** 棵子树
2. 非叶根结点至少有 **2** 棵子树
3. 除根外的非叶结点至少有 **⌈m/2⌉** 棵子树
4. 所有叶结点在同一层
5. 含 k 棵子树的结点含有 **k-1** 个关键字

### 关键字数范围
- 根结点：1 到 m-1 个关键字
- 非根非叶结点：⌈m/2⌉-1 到 m-1 个关键字

---

## B树 vs B+树

| 特性 | B树 | B+树 |
|------|-----|------|
| 数据存放 | 所有结点 | 只在叶结点 |
| 叶结点链接 | 无 | 链表连接 |
| 查找效率 | O(log n) | O(log n)（更稳定） |
| 适合场景 | 文件索引 | 数据库索引 |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ m阶B树：非根非叶结点关键字数 **⌈m/2⌉-1 到 m-1**
2. ⭐⭐⭐ B树**插入**：若结点关键字满（m-1个），需要**分裂**，中间关键字上移
3. ⭐⭐ B树**删除**：若结点关键字少于⌈m/2⌉-1，需要**合并**或**借键**
4. ⭐⭐ B+树与B树的区别：B+树叶结点用链表连接，支持顺序访问
5. ⭐ B树高度 h = O(log_m(n))
