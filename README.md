## ⭐ 各章节重要考点

| 章节 | 核心考点 |
|------|---------|
| 线性表 | 顺序表插删时间复杂度、链表逆置、循环队列判满判空 |
| 树 | 二叉树遍历序列、BST删除、AVL旋转、哈夫曼编码、B树阶数 |
| 图 | Dijkstra不适用负权、Floyd时间O(n³)、Prim适合稠密图、Kruskal适合稀疏图 |
| 查找 | 折半查找判定树、散列冲突处理、装填因子 |
| 排序 | 稳定性分析、各算法最优/最坏/平均时间复杂度 |

## 📊 时间/空间复杂度汇总表

### 排序算法

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 直接插入排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 希尔排序 | O(n log n) | O(n^1.3) | O(n²) | O(1) | ❌ 不稳定 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ 不稳定 |
| 简单选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✅ 稳定 |

### 查找算法

| 算法 | 平均时间复杂度 | 适用场景 |
|------|--------------|---------|
| 顺序查找 | O(n) | 无序/有序线性表 |
| 折半查找 | O(log n) | 有序顺序表 |
| BST查找 | O(log n) 平均，O(n) 最坏 | 动态查找 |
| 散列查找 | O(1) | 已知散列函数 |
