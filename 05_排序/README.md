# 第五章 排序

## 概念定义

**排序**是将一组数据按照某个关键字的大小重新排列的过程。

### 稳定性
若排序前后相同关键字的相对顺序不变，称为**稳定排序**。

---

## 各排序算法总览

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 直接插入排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 希尔排序 | O(n log n) | O(n^1.3) | O(n²) | O(1) | ❌ 不稳定 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ 不稳定 |
| 简单选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✅ 稳定 |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **稳定的排序**：插入（直接插入、折半插入）、冒泡、归并、基数
2. ⭐⭐⭐ **不稳定的排序**：希尔、快速、简单选择、堆
3. ⭐⭐⭐ 快速排序在**最坏情况**（已有序）退化为O(n²)，**最好和平均**是O(n log n)
4. ⭐⭐⭐ 堆排序适合**Top-K问题**，建堆时间O(n)
5. ⭐⭐ 归并排序需要O(n)额外空间（唯一需要O(n)空间的O(n log n)排序）
6. ⭐⭐ 基数排序不基于比较，适合关键字范围小、位数少的情况
7. ⭐ 排序算法的**比较次数**和**移动次数**分析
