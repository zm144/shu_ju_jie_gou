# 归并排序

## 概念定义

**归并排序**采用**分治**策略：
1. **分**：将数组从中间分成两半
2. **递归**：对两半分别排序
3. **合**：将两个有序子数组合并为一个有序数组

---

## 时间/空间复杂度

| 情况 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最好/平均/最坏 | O(n log n) | O(n) |

- 归并排序时间复杂度在所有情况下都是 **O(n log n)**
- 需要 **O(n) 额外空间**（合并需要辅助数组）
- 这是**唯一**需要O(n)空间的O(n log n)排序（堆排序和快速排序只需O(1)/O(log n)）

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 归并排序**稳定** ✅（合并时保持相等元素的相对顺序）
2. ⭐⭐⭐ 归并排序需要**O(n)额外空间**（与堆排序、快排不同）
3. ⭐⭐ **外部排序**的核心是多路归并（磁盘数据排序）
4. ⭐⭐ 2路归并：每次合并相邻的两个有序段
5. ⭐ 归并排序的**迭代版本**（自底向上）避免了递归栈空间

---

## 历年真题关注点

- 归并排序每趟结束后的结果（2路归并）
- 归并排序与其他排序的比较
- 外部排序中归并路数的选择
