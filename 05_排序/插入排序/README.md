# 插入排序

## 直接插入排序

将未排序的元素逐一插入到已排序部分的正确位置。

- 最好：O(n)（已有序），最坏：O(n²)（逆序）
- 稳定，空间O(1)
- **适合基本有序的数据**

## 折半插入排序

查找插入位置时用折半查找代替顺序查找，减少**比较次数**，但移动次数不变。

- 时间复杂度仍为O(n²)（移动次数未减少）
- 稳定

## 希尔排序（缩小增量排序）

按递减的增量序列分组，对每组做直接插入排序。

- 时间复杂度依赖增量序列，约O(n^1.3)
- **不稳定**（跨组移动打乱相对顺序）

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 直接插入排序**稳定**，比较次数最好O(n)（已有序时）
2. ⭐⭐ 折半插入减少**比较次数**但不减少**移动次数**，总时间仍O(n²)
3. ⭐⭐ 希尔排序**不稳定**（唯一不稳定的插入类排序）
4. ⭐ 希尔排序最后一趟增量为1，相当于一次直接插入排序
