# 基数排序（Radix Sort）

## 概念定义

**基数排序**是一种不基于比较的排序算法，通过对关键字各位数字依次排序来实现。

### LSD（Least Significant Digit，从低位到高位）
从最低位到最高位，对每一位做一次稳定排序（通常用计数排序）。

### MSD（Most Significant Digit，从高位到低位）
从最高位到最低位，递归处理。

---

## 时间/空间复杂度

设有 n 个元素，每个元素有 d 位，每位有 r 种取值（基数）：

| 情况 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 所有情况 | O(d(n+r)) | O(n+r) |

- 当 d 和 r 较小时，接近 **O(n)**（线性时间排序）

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 基数排序**不基于比较**，可以突破比较排序O(n log n)下界
2. ⭐⭐⭐ 基数排序**稳定** ✅（每趟的稳定排序保证整体稳定）
3. ⭐⭐ 时间复杂度 O(d(n+r))：d=位数，n=元素数，r=基数（进制）
4. ⭐⭐ 适用场景：关键字可以按位分解，且位数d和基数r较小
5. ⭐ LSD基数排序每趟必须使用**稳定**的内部排序
