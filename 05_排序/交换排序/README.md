# 交换排序

## 冒泡排序

每趟将相邻逆序对交换，较大元素"冒泡"到右端。

- 最好：O(n)（已有序，一趟无交换即停止），最坏：O(n²)
- 稳定 ✅，空间O(1)

## 快速排序

选一个基准（pivot），将数组分为左（≤pivot）和右（≥pivot）两部分，递归排序。

- 最好/平均：O(n log n)，最坏：O(n²)（已有序时退化）
- 不稳定 ❌，空间O(log n)（递归栈）
- **实际性能最优的排序算法之一**

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 快速排序**最坏情况为O(n²)**（当数组已有序，每次划分极不均匀）
2. ⭐⭐⭐ 快速排序平均是O(n log n)，**实际最快**的通用排序
3. ⭐⭐⭐ 快速排序**不稳定**
4. ⭐⭐ 快速排序的空间复杂度：平均O(log n)，最坏O(n)（递归深度）
5. ⭐⭐ 改进：随机选择pivot可降低最坏情况概率
6. ⭐ 冒泡排序可以通过检测是否有交换来**提前退出**（最好O(n)）
