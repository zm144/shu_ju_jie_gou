# 选择排序

## 简单选择排序

每趟从未排序部分选出最小元素，放到已排序部分末尾。

- 时间：O(n²)（比较次数固定，与输入无关）
- 不稳定 ❌（交换可能改变相同元素的相对顺序）
- 空间：O(1)

## 堆排序

利用堆的性质，将最大值（大根堆）不断移到末尾。

- 时间：**O(n log n)**（无论最好最坏）
- 不稳定 ❌
- 空间：O(1)
- **建堆**时间：O(n)（从最后一个非叶结点开始，向下调整）

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **堆**的定义：满足父结点≥（或≤）子结点的完全二叉树
2. ⭐⭐⭐ **建堆**时间O(n)（不是O(n log n)），**堆排序**时间O(n log n)
3. ⭐⭐⭐ 简单选择排序的比较次数固定为 n(n-1)/2，与输入无关
4. ⭐⭐ 堆排序适合**Top-K问题**：在n个元素中找最大（小）k个，只需建堆后取k次
5. ⭐ 大根堆可用于升序排序（每次取出堆顶最大值）

---

## 历年真题关注点

- 手动建堆（从最后非叶结点开始向下调整）
- 堆排序的一趟排序结果
- 判断某数组是否满足堆的性质
