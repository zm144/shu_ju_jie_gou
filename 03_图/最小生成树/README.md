# 最小生成树（Minimum Spanning Tree，MST）

## 概念定义

**生成树**：连通图的一个极小连通子图，包含图的全部顶点，但只有 n-1 条边（n为顶点数）。  
**最小生成树**：带权连通图中，边权之和最小的生成树。

---

## Prim算法 vs Kruskal算法

| 特性 | Prim | Kruskal |
|------|------|---------|
| 核心思想 | 从一个顶点出发，贪心地加入最小代价边 | 按边权从小到大加入，不形成环 |
| 时间复杂度 | O(V²)（朴素） | O(E log E)（排序）|
| 适合场景 | **稠密图** | **稀疏图** |
| 数据结构 | 优先队列/数组 | 并查集 |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **Prim适合稠密图（O(V²)），Kruskal适合稀疏图（O(ElogE)）**
2. ⭐⭐⭐ Kruskal使用**并查集**判断是否形成环
3. ⭐⭐ 最小生成树**不唯一**（当有相同权值的边时）
4. ⭐⭐ 最小生成树的**MST性质**：对于图的任意一个切割，跨越切割的最小权边一定在某棵MST中
5. ⭐ 若图所有边权不同，最小生成树唯一
