# 第三章 图

## 概念定义

**图**由顶点集 V 和边集 E 组成，记为 G=(V, E)。

### 基本术语
- **有向图**：边有方向（弧）
- **无向图**：边无方向
- **完全图**：任意两顶点间都有边（无向完全图有 n(n-1)/2 条边）
- **连通图**：任意两顶点间都有路径
- **强连通图**：有向图中，任意两顶点间互相有路径

---

## 存储方式对比

| 特性 | 邻接矩阵 | 邻接表 |
|------|---------|-------|
| 空间复杂度 | O(V²) | O(V+E) |
| 查找边(u,v) | O(1) | O(度) |
| 遍历所有边 | O(V²) | O(V+E) |
| 适用场景 | 稠密图 | 稀疏图 |

---

## 重要算法复杂度

| 算法 | 邻接矩阵 | 邻接表 |
|------|---------|-------|
| DFS / BFS | O(V²) | O(V+E) |
| Dijkstra（朴素）| O(V²) | O((V+E)logV) |
| Floyd | O(V³) | O(V³) |
| Prim（朴素）| O(V²) | — |
| Kruskal | O(E log E) | O(E log E) |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **Dijkstra不能处理负权边**，Floyd可以（但不能处理负权环）
2. ⭐⭐⭐ **Prim适合稠密图**（O(V²)），**Kruskal适合稀疏图**（O(ElogE)）
3. ⭐⭐⭐ BFS的时间复杂度取决于存储结构（邻接表O(V+E)，邻接矩阵O(V²)）
4. ⭐⭐ 拓扑排序用于检测**有向图是否有环**
5. ⭐⭐ 最小生成树的**MST性质**（切割性质）
