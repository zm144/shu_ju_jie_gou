# 最短路径

## Dijkstra算法

**单源最短路径**（从一个源点到所有其他顶点的最短路径）
- 时间复杂度：朴素 **O(V²)**，堆优化 **O((V+E)logV)**
- ⭐ **不能处理负权边**

### 算法思路
1. 初始化：源点距离=0，其余=∞
2. 每次选取未访问的最小距离顶点 u
3. 松弛 u 的所有邻边：若 dist[v] > dist[u] + w(u,v)，则更新

---

## Floyd算法

**多源最短路径**（所有顶点对之间的最短路径）
- 时间复杂度：**O(V³)**
- 空间复杂度：**O(V²)**
- 可以处理负权边，但**不能处理负权环**

### 算法思路
动态规划：`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ Dijkstra**不能处理负权边**（这是常考考点）
2. ⭐⭐⭐ Floyd时间复杂度 **O(V³)**，三重循环
3. ⭐⭐ Dijkstra基于**贪心**思想（每次选择最小距离的未访问顶点）
4. ⭐⭐ Floyd基于**动态规划**思想
5. ⭐ BFS可求**无权图**单源最短路径（O(V+E)）
