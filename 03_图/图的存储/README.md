# 图的存储

## 邻接矩阵

用二维数组 `A[V][V]` 存储，`A[i][j]` 表示顶点 i 到顶点 j 的边权（0或无穷表示无边）。

- 无向图的邻接矩阵是**对称矩阵**
- 适合**稠密图**（边数接近V²）
- 空间：O(V²)

## 邻接表

每个顶点有一个链表，链表中存储该顶点的所有邻居。

- 适合**稀疏图**（边数远小于V²）
- 空间：O(V+E)

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 邻接矩阵空间O(V²)，与边数无关；邻接表O(V+E)
2. ⭐⭐ 无向图邻接矩阵是对称矩阵，可用压缩存储
3. ⭐ 有向图的入度通过**逆邻接表**可以O(度)获取
