# 图的遍历

## DFS（深度优先搜索）

类似于树的先序遍历，从起始顶点出发，尽可能深地搜索。
- 使用**栈**（递归隐式使用调用栈）
- 时间复杂度：邻接表 **O(V+E)**，邻接矩阵 **O(V²)**

## BFS（广度优先搜索）

类似于树的层序遍历，从起始顶点出发，按层扩展。
- 使用**队列**
- 时间复杂度：邻接表 **O(V+E)**，邻接矩阵 **O(V²)**

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ BFS可以求**无权图**的最短路径（跳数最少）
2. ⭐⭐⭐ DFS可用于检测**有向图中的环**（发现后向边则有环）
3. ⭐⭐ DFS/BFS生成树：连通无向图的一次遍历产生一棵**生成树**
4. ⭐⭐ 非连通图需要多次调用DFS/BFS，每次生成一棵树，总称**生成森林**
5. ⭐ 拓扑排序 = DFS后序逆序（对有向无环图）
