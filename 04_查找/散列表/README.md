# 散列表（Hash Table）

## 概念定义

**散列表**（哈希表）通过散列函数将关键字映射到存储地址，实现近似O(1)的查找。

### 核心概念
- **散列函数 h(key)**：将关键字映射到地址的函数
- **冲突（碰撞）**：不同关键字映射到相同地址
- **装填因子 α = n/m**：已存元素n与表长m的比值，α越大冲突越多

---

## 冲突处理方法

### 开放地址法
- **线性探测**：冲突时依次探测下一个位置，`h(key, i) = (h(key) + i) % m`
- **平方探测**：`h(key, i) = (h(key) + i²) % m`
- **双重散列**：`h(key, i) = (h1(key) + i×h2(key)) % m`

### 链地址法（拉链法）
- 每个槽维护一个链表，冲突元素存入链表
- 适合频繁插入删除的场景

---

## 时间复杂度

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | O(1) | O(n) |
| 插入 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ **装填因子 α = n/m**，α越大，冲突越多，ASL越大
2. ⭐⭐⭐ 开放地址法删除：不能直接删除，需**标记为"已删除"**（否则破坏探测链）
3. ⭐⭐ 常用散列函数：**除留余数法** `h(key) = key % p`（p为不大于m的最大质数）
4. ⭐⭐ 线性探测易产生**聚集（堆积）**现象
5. ⭐ 散列表的ASL = f(α)，与关键字个数无关，只与装填因子有关
