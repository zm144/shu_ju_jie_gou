# 第四章 查找

## 概念定义

**查找**是在数据集合中寻找满足条件的数据元素的过程。

### 评价标准
- **平均查找长度（ASL）**：查找成功时关键字比较次数的平均值
- ASL_成功 = Σ(pᵢ × cᵢ)，pᵢ为第i个元素查找概率，cᵢ为比较次数

---

## 各查找算法比较

| 算法 | 平均时间 | 最坏时间 | 适用条件 |
|------|---------|---------|---------|
| 顺序查找 | O(n) | O(n) | 任意线性表 |
| 折半查找 | O(log n) | O(log n) | **有序顺序表** |
| 斐波那契查找 | O(log n) | O(log n) | 有序顺序表 |
| BST查找 | O(log n) | O(n) | 动态查找 |
| 散列查找 | O(1) | O(n) | 已知散列函数 |

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 折半查找**必须是有序的顺序表**（不适用于链表）
2. ⭐⭐⭐ 折半查找的**判定树**：成功查找的ASL = O(log₂n)
3. ⭐⭐⭐ 散列表**冲突处理**：开放地址法（线性探测、平方探测）和链地址法
4. ⭐⭐ 散列表**装填因子 α = n/m**（n=元素数，m=表长），α越大冲突越多
5. ⭐ 斐波那契查找比折半查找在**比较次数**上稍少（但计算更复杂）
