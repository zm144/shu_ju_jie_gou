# 顺序查找与折半查找

## 顺序查找（Sequential Search）

- 从表的一端依次比较，找到即返回
- 适用：**有序/无序，顺序表/链表**
- ASL_成功 = (n+1)/2，ASL_失败 = n
- 时间复杂度：**O(n)**

## 折半查找（Binary Search）

- 每次与中间元素比较，排除一半
- 适用：**有序顺序表**（不适用于链表）
- ASL_成功 ≈ log₂(n+1) - 1
- 时间复杂度：**O(log n)**

### 判定树
折半查找可用**判定树**（类似BST）分析：
- 成功比较次数 = 该元素所在层数
- 失败结点在最后一层或倒数第二层

## 斐波那契查找

- 类似折半查找，但分割点在斐波那契数列处（黄金分割比）
- 时间复杂度：**O(log n)**

---

## ⭐ 考研重点提示

1. ⭐⭐⭐ 折半查找的**前提：有序顺序表**
2. ⭐⭐⭐ 折半查找判定树高度 h = ⌈log₂(n+1)⌉
3. ⭐⭐ n=11时，折半查找成功的ASL = (1×1+2×2+4×3+4×4)/11 = 3
4. ⭐ 顺序查找可用**哨兵**优化（将目标值放在表尾，减少边界判断）
